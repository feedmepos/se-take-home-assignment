# McDonald's Kitchen Chaos

A McDonald's order management system built with **React** (frontend) and **Node.js** (backend CLI).

## Project Structure

```
├── frontend/          # React + Vite UI
├── backend/           # Node.js CLI application
│   ├── src/
│   │   ├── index.js        # CLI entry point
│   │   ├── OrderManager.js # Order queue logic
│   │   ├── BotManager.js   # Bot worker logic
│   │   └── logger.js       # Timestamped logger
│   └── tests/
├── script/
│   ├── build.sh    # Install dependencies
│   ├── test.sh     # Run unit tests
│   └── run.sh      # Run CLI simulation → result.txt
├── .github/workflows/backend-verify-result.yml
└── result.txt      # Generated by run.sh
```

## Frontend

```bash
cd frontend
npm install
npm run dev      # dev server on http://localhost:3000
npm run build    # production build
```

## Backend CLI

### Interactive mode

```bash
cd backend
npm install
node src/index.js [output-file]
```

Available commands:
| Command | Description |
|---|---|
| `new_normal_order` | Add a normal order to the end of the queue |
| `new_vip_order` | Add a VIP order (before all normal orders) |
| `new_bot` | Add a bot worker |
| `del_bot` | Remove the most recently added bot |
| `status` | Print current queue and bot state |
| `exit` | Close the kitchen |

### Simulation mode (GitHub Actions)

```bash
BOT_PROCESSING_TIME=3000 node src/index.js --simulate result.txt
```

### Via scripts

```bash
bash script/build.sh   # install deps
bash script/test.sh    # unit tests
bash script/run.sh     # simulate → result.txt
```

## Rules implemented

- Normal orders queue at the **end**
- VIP orders queue **after the last VIP** but **before all normals**
- Each bot picks up the next pending order automatically
- Removing a bot returns its in-progress order to the correct priority position
- `result.txt` includes `[HH:MM:SS]` timestamps on every line
