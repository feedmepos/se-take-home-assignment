# CLI Commands

Hermes is a TypeScript Node.js CLI project. Run commands from the repository root.

## Development Commands

```bash
npm install
npm run build
npm test
npm run test:output
npm run cli
npm run cli:interactive
```

- `npm install` installs the TypeScript compiler from `package-lock.json`.
- `npm run build` compiles `src/**/*.ts` into `dist`.
- `npm test` compiles TypeScript and runs all unit and output tests.
- `npm run test:output` runs the CLI stdout contract tests.
- `npm run cli` runs the compiled CLI directly.
- `npm run cli:interactive` starts command-driven interactive mode.

## Assignment Scripts

```bash
./scripts/test.sh
./scripts/build.sh
./scripts/run.sh
```

- `./scripts/test.sh` is the GitHub Actions test entry point.
- `./scripts/build.sh` is the GitHub Actions build entry point.
- `./scripts/run.sh` writes CLI output to `scripts/result.txt`.

## Current CLI Output Contract

- Output starts with `Hermes Order Controller - Simulation Results`.
- Event lines use `[HH:MM:SS]` timestamps.
- Output includes order creation, bot creation, order pickup, completion, and final status.
- `scripts/result.txt` must be generated by the CLI, not manually edited.

## Interactive CLI Commands

Start interactive mode:

```bash
npm run build
npm run cli:interactive
```

Then type commands at the `hermes>` prompt:

```text
normal
vip
bot+
tick 10
status
bot-
exit
```

In normal interactive use, processing also advances with real elapsed time. If a bot picks up an order at `00:00:00`, it will complete around `00:00:10` without another command. Use `tick <sec>` as a fast-forward command when you want to demonstrate the same behavior immediately.
