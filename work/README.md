# FeedMe 订单控制器

这是 FeedMe Software Engineer Take Home Assignment 的前端实现版本，用一个可交互页面演示麦当劳订单控制器的完整流程。

线上演示地址：http://38.244.31.190:13200/

## 功能清单

- 可以新增普通订单和 VIP 订单，订单编号唯一且递增。
- VIP 订单始终排在普通订单前面；同类型订单保持先进先出。
- 点击 `+ 机器人` 会新增一个机器人，并立即处理等待区中的订单。
- 每个机器人同一时间只能处理一笔订单，处理时间固定为 10 秒。
- 如果没有等待订单，机器人会保持空闲；新订单进入后，空闲机器人会自动开始处理。
- 点击 `- 机器人` 会移除最新创建的机器人；如果该机器人正在处理订单，该订单会回到等待区，并重新按照 VIP/普通优先级排队。
- 页面展示等待区、机器人/处理中、完成区、倒计时和事件日志，方便现场演示。

## 实现说明

核心调度逻辑放在 `src/domain/orderController.ts`。它是一个 reducer 风格的纯逻辑模块，React 页面只负责触发操作和展示状态。

这样拆分的好处是：

- 订单优先级、机器人分配、订单完成、机器人删除等规则都可以单独测试。
- UI 不直接处理复杂业务分支，代码更容易讲解和维护。
- 面试演示时可以先展示页面效果，再打开核心逻辑说明状态如何流转。

## 核心状态

- `pendingOrders`：等待处理的订单队列。
- `bots`：当前机器人列表，包含空闲和处理中两种状态。
- `completedOrders`：已经处理完成的订单。
- `nextOrderId` / `nextBotId`：保证订单和机器人编号递增。
- `log`：页面下方展示的事件日志。

## 主要规则

1. 新增普通订单：进入等待队列尾部。
2. 新增 VIP 订单：排到所有普通订单前面，但排在已有 VIP 订单后面。
3. 新增机器人：如果有等待订单，立即取队首订单处理。
4. 订单处理：机器人处理满 10 秒后，订单进入完成区。
5. 订单完成后：机器人自动检查等待区，如果还有订单则继续处理。
6. 删除机器人：始终删除最新创建的机器人；如果它正在处理订单，该订单会回到等待队列。
